# MediBook — Doctor Appointment Booking System Frontend

A complete static frontend prototype for the college minor project.

## Included pages
- Home / landing page
- Doctor listing + search
- Doctor profile + slot selection
- Appointment booking
- Login + registration
- Patient dashboard
- Doctor dashboard
- Admin dashboard
- Appointment list

## Tech
HTML5, CSS3, Vanilla JavaScript. No backend is connected yet.

## Run
Open `index.html` in a browser, or use VS Code Live Server.
